# 🛡️ Team Centinels

Welcome to the official GitHub Organization of **Team Centinels**, the premier student-led cybersecurity and Capture The Flag (CTF) collective at **SRM Institute of Science and Technology, Kattankulathur**. 

We are a community of ethical hackers, security researchers, and developers dedicated to exploring defensive and offensive security, building tools, and competing in global CTFs.

---

## 🎯 Our Focus Areas

*   **🏆 Capture The Flag (CTF):** Training and competing in Jeopardy and Attack-Defense style global competitions.
*   **💻 Vulnerability Research:** Identifying flaws, secure coding practices, and understanding malware mechanics.
*   **🌐 Infrastructure & Tools:** Building custom penetration testing scripts, automation workflows, and lab setups.
*   **📚 Knowledge Sharing:** Hosting weekly hands-on workshops, bootcamps, and internal war games.

## 🤝 Contribution Guidelines

To maintain standard repository hygiene, direct pushes to the `main` branch are blocked. All members must follow our branch protection workflow:

### 1. Fork & Clone
Fork this repository to your personal profile, then clone it locally:
```bash
git clone https://github.com
```

### 2. Create a Feature Branch
Never work directly on your local `main` branch. Create a distinct feature branch:
```bash
git checkout -b feat/your-feature-name
```

### 3. Commit Changes
Commit your changes using clear, conventional prefixes (`feat:`, `fix:`, `docs:`, `chore:`):
```bash
git commit -m "feat: added writeup for 2026 defcon ctf crypto challenge"
```

### 4. Push and Open a PR
Push the branch to your fork and submit a Pull Request back to the `TEAM-CENTINELS` repository:
```bash
git push origin feat/your-feature-name
```
*   Ensure your PR description clearly mentions what changes were made.
*   At least **1 peer review / approval** from a club admin or core member is required before merging.

## 📜 Club Code of Conduct

As a member of Team Centinels, you strictly adhere to legal and ethical computing frameworks:
1.  **Authorization:** Never test networks, systems, or software without explicit, written permission.
2.  **Responsibility:** Tools and scripts hosted here are strictly for educational and defensive exploration.
3.  **Academic Integrity:** Collaborate openly but protect official CTF flags during active, live competitions.
